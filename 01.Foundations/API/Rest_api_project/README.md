# Flask REST API Project

A simple REST API built with **Flask** and **Flask-SQLAlchemy** for practicing CRUD operations and API testing with Postman.

## Features

* GET — Retrieve notebooks and datasets
* POST — Create notebooks and datasets
* PUT — Replace resources
* PATCH — Partially update resources
* DELETE — Delete resources
* SQLite database using SQLAlchemy
* JSON request and response handling

## Tech Stack

* Python
* Flask
* Flask-SQLAlchemy
* SQLite
* Postman

## Resources

* `/notebook`
* `/dataset`

Each resource supports CRUD operations using appropriate HTTP methods.

## Run

```bash
python main.py
```

The API runs locally at:

```text
http://127.0.0.1:5000
```

This project is part of my **AI Engineering Journey** and was created to understand REST API fundamentals before moving to FastAPI.
